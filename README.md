# 🧩 My Local API

A simple local REST API built with **Express.js** and **SQLite**, supporting full **CRUD operations** (Create, Read, Update, Delete).  
You can use it to learn, test, or build small apps locally.

---

## 🚀 Features

✅ Built with **Express.js**  
✅ Uses **Sequelize ORM** with **SQLite**  
✅ Full CRUD user management  
✅ CORS and JSON body parsing  
✅ Clean and simple codebase
